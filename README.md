# 金廈員旅隨行手冊

手機優先、可直接部署的單頁旅行 Web App。行前清單、個人備忘與航班／住宿設定都只儲存在瀏覽器 LocalStorage，不會上傳個人資料。

## 行程來源

景點與座標已由使用者提供的「廈門員旅.kml」擷取，包含：

- 臺北松山機場、金門水頭港、五通客運碼頭
- 鼓浪嶼、萬國建築博覽、菽莊花園、鋼琴博物館、中山路步行街
- 廈門萬佳國際酒店、環島東路、靈玲國際馬戲城、靈玲動物王國、集美學村
- 廈門博物館、環島路

KML 不含日期、班機／船班號與集合時間，因此程式沒有猜測這些資訊；請於網站 PLAN 分頁的「旅程設定」填入。

## 使用方式

直接在瀏覽器開啟 `index.html` 即可使用主要功能。若部署至 GitHub Pages 或其他 HTTPS 靜態網站，Service Worker 會快取核心頁面，支援離線重新開啟。

## GitHub Pages

將本資料夾推送到 GitHub 儲存庫後，於 Settings → Pages 選擇部署分支的根目錄。首次開啟時需要網路載入 Tailwind、字體與圖示 CDN；之後核心頁面可離線使用。
